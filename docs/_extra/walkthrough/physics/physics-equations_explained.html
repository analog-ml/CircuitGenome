1. The analog background

What does a transistor turn into an amplifier?

A transistor converts a gate-voltage change into a drain-current change. The output node converts that current into voltage. Resistance determines gain; capacitance determines speed.

Transconductance: signal strength

gm is the small-signal conversion from gate voltage to drain current.

\(g_m = \frac{dI_D}{dV_{GS}}\)

Higher gm means more signal current for the same input change. Real devices also have a practical ceiling of about 25 / V for gm/ID.

Output resistance: voltage gain

gd measures current leakage as output voltage changes. The top and bottom devices leak in parallel, so:

\(r_{\mathrm{out}} = \frac{1}{g_{d,\mathrm{top}} + g_{d,\mathrm{bot}}}\)

The stage gain is approximately:

\(A_v = g_m r_{\mathrm{out}}\)

Headroom, capacitance, and feedback

VDSAT is the minimum drain-source voltage needed for saturation. Stacked devices consume stacked headroom. A capacitor follows I = C * dV/dt: it creates bandwidth limits for small signals and slew-rate limits for large signals. Feedback adds phase delay, so phase margin measures how far the loop is from oscillation.

Damping ratio and RNMC

Phase margin alone does not describe how a pair of nearby poles behaves. The damping ratio ζ describes the angle of a pole pair from the negative real axis:

\(\zeta = -\frac{\operatorname{Re}(p)}{|p|}\)

A value near ζ = 0.7 is the Butterworth target: the response is fast without a resonant peak. Values near zero produce ringing, while a negative value means that a pole has crossed into the right half plane and the loop is unstable.

RNMC (reversed nested-Miller compensation) places the compensation capacitors so that the two non-dominant poles form a coupled pair. A simple two-real-pole phase-margin equation can therefore look healthy while missing ringing or instability. The RNMC model solves the nodal equations, finds the poles, and reports the worst non-dominant damping ratio and the worst phase margin across all unity-gain crossings.

\(\zeta_{\mathrm{RNMC}} = \min\left\{-\frac{\operatorname{Re}(p)}{|p|}\right\}\)

The sizing helper raises gm2 until the RNMC pair reaches the requested ζ; the full-model check then includes parasitic capacitances, conductances, mirror poles, and an output buffer when present.

2. One small numerical example

Assume:

mu_cox = 200 uA/V^2,  W = 10 um,  L = 1 um
|IDS| = 100 uA,        Vth = 0.45 V, lambda = 0.10 / V

First find the voltage room and gate voltage:

\(\displaystyle V_{\mathrm{DSAT}} = \sqrt{\frac{2|I_{DS}|L}{\mu_{\mathrm{ox}}W}}, \qquad V_{GS} = V_{\mathrm{th}} + V_{\mathrm{DSAT}}\) 
VDSAT = sqrt(2 * 100 uA * 1 / (200 uA/V^2 * 10)) = 0.316 V
VGS   = Vth + VDSAT = 0.45 + 0.316 = 0.766 V

Then find strength, leakage, and gain. If the load contributes another 10 uS:

\(\displaystyle g_m = \sqrt{2\mu_{\mathrm{ox}}\frac{W}{L}|I_{DS}|}, \qquad g_d = \lambda|I_{DS}|, \qquad r_{\mathrm{out}} = \frac{1}{g_{d,\mathrm{top}}+g_{d,\mathrm{bot}}}, \qquad A_v = g_m r_{\mathrm{out}}\) 
gm   = sqrt(2 * 200 uA/V^2 * 10 * 100 uA) = 20 mS
gd   = lambda * |IDS| = 10 uS
rout = 1 / (10 uS + 10 uS) = 50 kOhm
Av   = gm * rout = 1000 V/V = 60 dB

Interpretation: gm supplies signal strength; rout supplies voltage leverage.

Device physics

Analog ideaCorresponding code
Voltage controls current\(g_m = \sqrt{2\mu_{\mathrm{ox}}\frac{W}{L}|I_{DS}|}\)
def gm(mu_cox, w_um, l_um, ids_a):
    return sqrt(2 * mu_cox * (w_um / l_um) * abs(ids_a))
gm() returns transconductance.
Real devices have a gm/ID limit\(\frac{g_m}{|I_{DS}|} \leq 25\,\mathrm{V}^{-1}\)
def gm_ceiling(ids_a):
    return 25.0 * abs(ids_a)
gm_ceiling() returns the weak-inversion ceiling.
Current leaks with output voltage\(g_d = \lambda|I_{DS}|\)
def gd(lam, ids_a):
    return lam * abs(ids_a)
gd() returns output conductance.
Two leaks share one output\(r_{\mathrm{out}} = \frac{1}{g_{d,\mathrm{top}}+g_{d,\mathrm{bot}}}\)
def rout(gd_top, gd_bot):
    total = gd_top + gd_bot
    return 1.0 / total if total > 0 else inf
rout() returns stage output resistance.
Bias sets headroom\(V_{\mathrm{DSAT}} = \sqrt{\frac{2|I_{DS}|L}{\mu_{\mathrm{ox}}W}}\)
def vds_sat(mu_cox, w_um, l_um, ids_a):
    return sqrt(2 * abs(ids_a) * l_um / (mu_cox * w_um))
vds_sat() returns the minimum saturation voltage.
